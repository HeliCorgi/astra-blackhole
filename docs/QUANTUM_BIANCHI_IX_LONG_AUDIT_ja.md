# Bianchi IX量子波束：第二・第三壁までの分岐と干渉監査

## 結論

第一壁監査と**同じ真空・一様Bianchi IXの古典主記号**と、同じ直接平方根量子化を保ったまま、有限箱を段階的に拡大して `s=36` まで進めた。中央の古典軌道では第二壁が `s≈10.385` の `B-`、第三壁が `s≈32.46` の `B+` である。

第三壁まで進めても、量子状態を一本の軌道へ置き換えることはできない。一方、量子平均が一本の古典軌道から大きく離れることの大部分は、同じ初期Gaussian Wigner分布を古典Hamilton流で進めた**古典集団の広がり**でも再現される。したがって「一本軌道からの差」を全部量子効果とは数えない。

### 壁セクター質量

`A/B+/B-` は、各 `(beta_+,beta_-)` で三つの正の漸近Mixmaster壁のうち最大のものを選ぶ一時刻の位置セクターである。**未来にどの壁を衝突するかというconsistent-histories確率ではない。**

|中央古典壁|量子セクター質量 A/B+/B-|古典Wigner集団 A/B+/B-|全変動距離|
|---|---|---|---:|
|第二壁 `B-`, s=10.385|0.100865 / 0.172971 / 0.726164|0.097900 / 0.171387 / 0.730713|0.00455|
|第三壁 `B+`, s=32.46|0.304096 / 0.366982 / 0.328923|0.222656 / 0.424316 / 0.353027|0.08144|

第二壁では量子と古典集団の壁セクター分布はかなり近い。第三壁では差が広がる。ただし中央古典軌道が `B+` を一本だけ選ぶのに対し、量子状態も古典集団も三セクターへ広く分布している。

## 干渉診断

壁直前の状態を三セクターへ射影し、同じ線形量子発展で各成分を別々に進めた。最後に、コヒーレントな和 `|psi_A+psi_B++psi_B-|^2` と、位相を捨てた非干渉混合 `|psi_A|^2+|psi_B+|^2+|psi_B-|^2` を比較する。これは選んだセクター分解に依存する診断であり、唯一の量子履歴定義ではない。

- 第二壁: `s=9.5 -> 11`、密度の半L1差 `≈0.09094`、最終壁セクターの全変動差 `≈0.02724`。
- 第三壁: `s=30 -> 34`、密度の半L1差 `≈0.14082`、最終壁セクターの全変動差 `≈0.01525`。

したがって、低次の平均・分散が古典集団に近くても、**位相を消すと同じ密度発展にはならない**。これは「量子状態が単なる古典軌道集団と同一」という解釈を否定するが、長時間の量子カオスを証明するものではない。

## BKL列との接続

同じ中央古典軌道のKasnerパラメータは `s=2,6,15,36` で `1.7112429 -> 1.4056553 -> 2.4651063 -> 1.4651063`。標準BKL写像の相対誤差は順に約 `2.38e-4`, `1.67e-5`, `2.6e-10`。第三壁まで連続Bianchi IXとBKL列の対応が維持された。

## 数値レギュレータ

同じ箱を巨大化すると初期波束の空間解像度が落ちるため、`s=6,12,20` で有限箱を拡大し、物理波動関数を三次補間した。これは非ユニタリな数値介入なので隠さない。往復fidelityは `0.9999929, 0.9999460, 0.9998830`、積は `0.9998218`。

採用した保存時刻で、境界から1単位以内の最大確率は約 `1.97e-4`、ポテンシャルcapの半分より大きい領域の最大確率は約 `4.16e-6`。第三壁近傍では時間刻み、Krylov次数、cap 30->50、格子 214x240->240x270 を個別に変更した。壁セクター全変動差はいずれも約 `0.0013` 以下だった。これは連続理論への厳密誤差上限ではない。

## 位置づけ

Bojowald, Brizuela, Calizaya Cabrera, Uria, *Phys. Rev. D* **109**, 044038 (2024) は、量子揺らぎを拡張位相空間で扱い、Bianchi IXのカオスは量子効果で弱まるが残ると報告している。今回の直接2次元波束法とは異なる。

Brizuela, Uria, *Phys. Rev. D* **106**, 064051 (2022) は半古典的な量子Kasner写像を導出している。今回の監査は、その写像を再現したものではなく、同じ古典主記号の波束・古典集団・中央軌道を有限の三壁区間で直接比較したもの。

## 限界

実在ブラックホール内部の観測ではない。Bianchi IXは一様ミニ超空間であり、一般の空間依存自由度を含まない。平方根演算子・平坦なbeta面L2内積は一つの量子化選択で、唯一のWDW物理内積ではない。第三壁後より先の長時間量子カオス、特異点解消、曲率演算子の有限性はこの監査からは結論しない。
