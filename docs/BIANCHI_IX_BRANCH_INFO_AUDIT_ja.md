# Bianchi IX壁セクターの情報量監査

## 結論

第三壁までの長時間Bianchi IX監査で保存した `A/B+/B-` の一時刻セクター質量を、情報量として再評価した。**新しい時間発展は行っていない。**

第一壁付近 `s=4.6` では量子状態のセクターエントロピーは約 `0.154 bit`、有効セクター数 `2^H≈1.113` で、約97.97%が一つのセクターにある。第二壁 `s=10.385` では `H≈1.107 bit`, 有効セクター数 `≈2.154`。第三壁 `s=32.46` では `H≈1.581 bit`、有効セクター数 `≈2.991` となり、3セクターの最大値 `log2(3)≈1.585 bit` の約99.73%に達した。

従って、この選んだ配置空間分割では、**第三壁では「一本の壁ラベル」で量子状態を要約するのは非常に情報を失う。** ただし、これは「三つの実在する歴史へ分岐した確率」を証明したものではない。元のセクター質量は一時刻の配置空間確率であり、consistent histories の確率ではない。

## 1. 定義

三つの正の漸近Bianchi IX壁指数 `A/B+/B-` のうち、その点で最大のものに配置空間点を割り当てる。保存済み確率質量を `p_i` とし、

\[
H=-\sum_i p_i\log_2 p_i,\qquad N_{eff}=2^H
\]

を使う。`N_eff=1` は一セクター集中、`N_eff=3` は三セクター等分に対応する。

量子と同じ初期Wigner Gaussianを古典Hamilton流で進めた集団も同じ分割で採点する。両者の差には total variation と Jensen-Shannon divergence を使う。

## 2. 三つの代表時刻

|s|量子H [bit]|量子有効セクター数|量子最大セクター|古典集団H [bit]|量子-古典TV|
|---:|---:|---:|---:|---:|---:|
|4.6|0.15395|1.1126|0.97974|0.26172|0.01905|
|10.385|1.10689|2.1538|0.72616|1.09508|0.00455|
|32.46|1.58064|2.9910|0.36698|1.53761|0.08144|

第二壁では量子と古典集団の壁セクター分布は非常に近い。Jensen-Shannon divergence は約 `2.37e-5 bit`。第三壁では差が大きくなり、JS divergence は約 `0.00637 bit` となる。これは依然として小さい絶対情報量だが、保存した第三壁の局所数値対照の最大wall-sector TV `0.001304` より、量子-古典TV `0.08144` は約62倍大きい。**この倍率は統計的有意度でも厳密誤差上限でもなく、観測された数値依存とのスケール比較に限る。**

## 3. 干渉を除いた混合との比較

既存の長時間監査では、壁直前に波束を三セクターへ射影し、各成分を別々に進めた非干渉混合と、コヒーレントな完全波束を短時間比較している。

- 第二壁: 配置空間密度の `L1/2≈0.09094`、最終セクターTV `≈0.02724`
- 第三壁: 配置空間密度の `L1/2≈0.14082`、最終セクターTV `≈0.01525`

第三壁のセクターTVは第三壁局所数値対照最大値の約11.7倍。したがって、**選んだセクター射影に関して、コヒーレント和と非干渉混合の差は保存した数値依存より大きい。** ただし射影の選択に依存する診断であり、デコヒーレンス汎関数や物理的測定過程を構成したものではない。

## 4. 「一本の軌道がない」の意味

この結果から言えるのは、第三壁付近では、量子状態を中央古典軌道が選ぶ一つの壁ラベルだけで表すと、保存した配置空間分布の大部分を捨てるということ。

言えないことは以下。

- 自然がランダムに三つの壁を選ぶと証明した。
- 三つのセクターが相互にデコヒーレンスした独立世界だと証明した。
- 一時刻セクター質量が次壁ヒット確率そのものだと証明した。
- Bianchi IX縮約が現実のブラックホール中心をそのまま表すと証明した。

より強い「壁選択履歴」の主張には、複数時刻の射影とデコヒーレンス汎関数を持つ consistent-histories 型の監査が必要。
