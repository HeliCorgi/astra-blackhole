# WDW波束の裾と、非有界な曲率関連量の期待値

Copyright 2026 HeliCorgi. Apache-2.0.

## 結論と範囲

既存の真空Kantowski–Sachs WDW模型、時計 T、L2(dx)内積、初期5波束、Hamiltonianは変えていない。**平均半径の幾何平均が安定しても、逆半径モーメントには有限値への収束が見られなかった。** 連続スペクトルの低エネルギー展開も、正の有限時刻で指数モーメントを発散させる代数的な裾を予測する。

ただし、**4次元Kretschmann演算子そのものは構成していない**。今回の量は球面固有曲率と、古典的な曲率／質量二乗を先に規格化した診断量。質量演算子の順序、物理内積・時計の独立性、測地線完全性、自然界の特異点の存否は別の課題である。数値領域拡大だけを無限領域の発散証明としない。以下の漸近解析の仮定と数値的な裏付けを分ける。

## 1. 何を「曲率」として計算したか

前回の選択を保持する：

\[
 ih\partial_T\psi=\sqrt{-h^2\partial_x^2+e^{-2x}}\,\psi,
 \quad r=\tfrac14e^{-x-T},\quad r_{ref}=\tfrac14e^{-x_0},\quad x_0=2.
\]

この表現でrは正の掛け算演算子。次を定義する。

\[
 J_q(T)=\int_{-\infty}^{\infty}e^{q(x+T-x_0)}|\psi(x,T)|^2dx.
\]

q=2は2球面の固有スカラー曲率 S=2/r² を基準値 S_ref で割った期待値。q=4はその二乗。**球面固有曲率は4次元時空曲率と同じではない**。平坦時空の中の球面にも固有曲率はある。

古典的なSchwarzschild真空ではK=48M²/r⁶（G=c=1）。そこでq=6を、古典的な商 r_ref⁶ K/(48M²) を先に簡約してから量子化した、規格化曲率診断として扱う。これは <K>/(48<M>²) ではなく、固定した数値Mを波束全体へ勝手に代入する操作でもない。この模型の波束を質量固有状態と同定していないため、**J6を完全な量子<K>と表示しない**。

正の非有界演算子の期待値が有限になる条件は、状態がその二次形式の定義域に属すること、ここでは ∫e^{qx}|ψ|²dx<∞。演算子自体の定義域に必要な ∫e^{2qx}|ψ|²dx<∞ とは区別する。正規化 ∫|ψ|²dx=1 だけでは、どちらも保証されない。

## 2. 切断を二つに分けた

計算領域の右端Rと、観測量の積分上限Lは別にする。

\[
 J_q^{(L)}=\int_{-\infty}^{L}e^{q(x+T-x_0)}|\psi|^2dx,
 \quad J_{q,cap}^{(L)}=\int e^{q(\min(x,L)+T-x_0)}|\psi|^2dx.
\]

前者は正の部分積分で、切り捨て後に確率を再規格化しない。後者は状態でなく観測量だけを上限付きにした別の有界量。固定Lで領域を広げた比較と、十分大きい領域内でLを広げた比較を記録する。有界量が計算できても、上限を外せるとは限らない。

全5波束を7格子、代表h=.2をさらに2格子で計算した計37格子・状態組、185時刻行。右端R=12,16,24,32、dx=.02を基準に、dx=.01、左端変更、大領域R=128も検査する。代表例はR=128,dx=.025とR=256,dx=.05も使う。T=0,.001,.5,2,6。プロトコルは予備計算後に固定したもので、未使用評価ではない。

大領域の比較は格子幅も異なるので、領域誤差と離散化誤差が混ざる。R=128でのdx=.04/.025比較を別に保持する。鋭い積分上限と一致する格子点は半分の重みとする。最初の矩形和で生じた上限点のO(dx)のずれを避ける数値積分上の処理で、波束の修正ではない。全領域和と有界化した期待値にこの端点修正は不要。

## 3. 数値結果：平均が安定しても期待値は安定しなかった

代表h=.2、sigma=√h、T=2、全てdx=.02：

|右端R|半径の幾何平均/初期基準|log10 J2（箱内）|log10 J6（箱内）|
|---:|---:|---:|---:|
|12|0.736628725|0.8440|20.0007|
|16|0.736628562|2.9606|29.2813|
|24|0.736628502|8.3428|48.5878|
|32|0.736628492|14.2233|68.3732|

**各Jは有限箱の規制された値で、収束した連続理論の期待値ではない。** R=32の最後の幅1にある確率は約3.41×10^-14なのに、その範囲が箱内J6の約93.48%を占めた。

同じ状態で右端を256に固定し、部分積分の上限だけ8,12,16,24,32,40,48と広げてもJ2,J4,J6は増え続けた。したがって右端に固定した反射の一例だけを見ているわけではない。ただし有限個の上限値だけから数学的な無限大は証明できない。詳細はcutoffs.json。

## 4. なぜ代数的な裾になるか：連続模型の閾値解析

z=e^-x/h と置く。二乗Hamiltonianの一般化固有関数はKontorovich–Lebedev変換の核で書ける。[1,2]

\[
 \phi_k(x)=\frac{\sqrt{2k\sinh(\pi k)}}{\pi}K_{ik}(z),\ k>0,
 \quad \widehat H\phi_k=hk\phi_k,
 \quad \psi(x,T)=\int_0^\infty a(k)\phi_k(x)e^{-ikT}dk.
\]

k→0で φ_k=√(2/π) k K0(z)+O(k³)。初期Gaussianのスペクトル係数について

\[
 a(k)=\sqrt{2/\pi}\,B k+O(k^3),\qquad
 B=\int K_0(e^{-y}/h)\psi_0(y)dy.
\]

右側x→∞ではBessel関数の小引数展開とGamma関数の位相展開を使う。[2,3]

\[
 \phi_k(x)\simeq\sqrt{2/\pi}\sin(kX+O(k^3)),
 \quad X=x+\log(2h)-\gamma_E.
\]

スペクトル係数が閾値で滑らかで、高エネルギー部分の積分とその導関数が十分減衰し、残差が上の閾値項より小さいという漸近展開の条件のもとで、Abel正則化した積分は

\[
 \int_0^\infty k e^{-(\epsilon+iT)k}\sin(kX)dk
 =\frac{2(\epsilon+iT)X}{[X^2+(\epsilon+iT)^2]^2}
 \xrightarrow{\epsilon\downarrow0}\frac{2iTX}{(X^2-T^2)^2}.
\]

従って固定したT>0、B≠0なら主要項は

\[
 \psi(x,T)\sim\frac{4iBT}{\pi X^3},\qquad
 |\psi(x,T)|^2\sim\frac{16|B|^2T^2}{\pi^2X^6}.
\]

**ここで係数は未来の裾へフィットせず、初期状態だけから計算した。** 代表h=.2では B≈0.00117312226203−0.0179950103531 i。5状態全てでBは積分の数値誤差と比較して非ゼロと分解できた。これは厳密な複素区間による非ゼロ証明ではない。

x=24〜48の密度の対数傾きは、R=128の5状態で約−6.019〜−6.058。R=256のh=.2では約−6.011。後者のx=48では初期状態からの主要項との比が約1.00074。R=128で格子を細かくした際の検査点密度の最大相対差は約2.83×10^-8。

この非ゼロの代数的主要項が成立すれば、任意q>0について ∫e^{qx}X^-6 dx=∞ なので、**J2,J4,J6の完全な期待値は有限ではない**。これはT→∞まで進めたためではなく、正周波数平方根発展と選択した表示の非有界観測量の組に関する主張である。ノルムとxの低次モーメントは代数的な裾と両立して有限であり得る。

本監査は上記の漸近導出と数値検証を提供するが、スペクトル残差の一様な厳密上界やLean形式証明は提供しない。**数値で直接確認した結論は有限値への収束不合格、連続無限領域の発散は明示した漸近条件に基づく結論**として分けて扱う。これは一般の量子重力模型・全量子状態に関する定理ではない。

## 5. 初期Gaussianの丸め誤差を別に検出した

T=0では解析的に Jq=exp(q²sigma²/2)。h=.2,q=6なら log10 J6=1.56346。ところが有限精度の固有ベクトルで U(U^T ψ0) を作るだけで、本来は極小の遠い裾に丸め誤差が入る。R=128の一回の実行では偽のlog10 J6が約296になった。この値はプラットフォーム依存の失敗対照で、回帰の固定目標にしない。

新しい監査では同じ伝播を ψ(T)=ψ0+U[(exp(-iET/h)−1)U^Tψ0] と評価し、expm1でT=0の入力を正確に保つ。元の直接式との差のL2ノルムは最大8.41×10^-15。時間ごとの再規格化、確率の切り詰め、低エネルギーの除去は行わない。既存wdw_model.py自体は変更しない。

**この対処で正時刻の代数的な裾は消えなかった。** 初期丸めノイズ、実際の平方根発展の裾、数値壁、観測量の上限を別々に扱う必要がある。

## 6. 古典対照・検証

同じ正の初期Wigner Gaussianを古典Hamilton流で進めると |dx/dT|≤1。従ってT≥0で

\[
 J_q(0)\le J_q^{classical}(T)\le e^{2qT}J_q(0)<\infty.
\]

有限時刻での有限性はこの解析的な上界による。Gauss–Hermite96/144点の数値積分も保存したが、大きなqの一部ではまだ収束が悪い。`quadrature_resolved_to_1e4_in_log=false` の値を高精度な基準値としない。

今回の数値検査では最大ノルムずれ2.22×10^-14、初期の解析的な対数モーメントとの最大差1.03×10^-15。これらは巨大な非有界モーメントの正しさを保証しない。新規15件と既存WDW15件の計30テストをローカルで実行した。従来の粒子/RTA/閉包の全監査は今回はローカルで再実行していない。既存CIは別途結果を確認する。Leanの既存命題・公理一覧は変更していない。

## 7. 再現と次の課題

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_wdw*.py' -v
python research/run_wdw_tail_audit.py --out artifacts/wdw-tails --check-against research/wdw_tail_results/summary.json
python research/plot_wdw_tails.py --results artifacts/wdw-tails
```

長いローカル実行を分ける場合は同じ出力先で `--phase core`, `wide`, `fine`, `large`, `assemble` を順に実行できる。全フェーズは独立に波束を再計算する。通常CIは一回のコマンドで全計算を行う。保存要約と選んだ安定な数値を照合し、失敗例の巨大な丸め依存値を無理に一致させない。

この結果から、物理的な特異点が存在すると観測したとも、量子化が無意味だとも言えない。次は**質量を含む4次元曲率の関係的演算子とその二次形式の定義域**、時計・内積選択に対する頑健性を検査する。有界化した曲率や閾値確率は別の観測量として利用できるが、上限を入れたことで特異点を解消したとは扱わない。裾を消す境界やスペクトル切断を後付けして成功扱いしない。
