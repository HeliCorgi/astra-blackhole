# 次の切り分け（未実施）

2026-09-16時点。以下は研究計画であり、計算済みの結果ではありません。

## 1. 角方向分布の省略

同じ初期エネルギー運動量テンソルと指定した低次モーメントを保ち、より高次の角方向分布だけを変える。正値性・重力の制約・初期一致を検査し、異方的な潮汐応答の差がどの式から入るかを調べる。

## 2. 衝突と反応時間

保存則と平衡極限に整合する衝突項を選ぶ。単純な摩擦係数を追加しただけで物理的な衝突を再現したとはしない。緩和時間と崩壊時間の比を変え、短い緩和時間の極限で平均記述が回復するかを対照とする。

## 3. 二粒子相関

一粒子分布を一致させ、二粒子の相関だけが異なる状態を比較する。平均値の違いと分散・相関の違いを分ける。現在の無衝突Vlasovコードでは未実装。

## 4. 量子応力の揺らぎ

量子状態、再正規化、粗視化、量子応力の反作用を明示した別のモデルが必要。量子補正という名前の任意関数を置いただけで自然界の量子効果を計算したとはしない。

## 共通の判定

各試験で、何を一致させ、何を変え、どの予測が区別不能になるかを明記する。差が出ない対照も保存する。数値誤差・測定誤差・モデルの省略を分け、学習データと採点データを分離する。追加仮説を使う場合は、実観測の検証と混同しない。
