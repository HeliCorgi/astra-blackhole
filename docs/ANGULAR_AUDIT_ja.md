# 方向分布の省略を切り分ける

2026-09-16。親コミット `08d708ff0ada45d66c2b658c2d92ce86d490ff48` の古典モデルを拡張した計算記録。

**合成データのモデル内実験である。現実の特異点解消、未知の自然法則、量子重力の検証、新規性の確定を主張しない。**

## 問い

前回は初期の方向分布を等方的に固定して、運動量の大きさの分布を変えた。今回は逆に、大きさの分布を完全に一致させ、方向分布だけを変える。同じ初期エネルギー運動量テンソルが、同じ未来を決めるかを調べる。

「圧力テンソルが初期に等方的」と「粒子分布が等方的」は同じではない。

## モデルと初期条件

一様な Kantowski–Sachs Einstein–Vlasov 系、`c=8*pi*G=1`、宇宙項ゼロ。

`ds^2=-dt^2+a(t)^2 dx^2+b(t)^2 dOmega^2`。

初期条件は `a=b=1, Ha=0.6, Hb=-1, rho=0.8`。初期制約 `2 Ha Hb+Hb^2+1/b^2=rho` を満たす。質量 `m=1` と `m=0` を別々に計算する。粒子数と全放射状スペクトルは各対の中で同じだが、質量が違うケース間で粒子数を一致させてはいない。

運動量の大きさは前回同様、10個の正の滑らかな対数正規核の混合。中心は `.05` から `8` の等比数列、対数幅 `.10`。重みは未来を見ず、初期密度を `.8` に規格化する。

初期の径方向余弦を `mu` として、方向分布を

`f_plus(q,mu)=f0(q)[1+alpha P_ell(mu)]`

`f_minus(q,mu)=f0(q)[1-alpha P_ell(mu)]`

とする。`P_ell` はLegendre多項式。`ell=4,6,8`, 主試験 `alpha=.8`。`|P_ell(mu)|<=1` なので全方向で分布は正、係数は最低 `.2`。偶数次数なので径方向反射対称性とゼロ流束を保つ。軸回転や正味角運動量を追加した実験ではない。

**初期の方向は保存運動量から運ぶ。毎時刻方向分布を等方化する操作はしない。** 時空の方程式は既存コードを使い、物質と時空の反作用を連立する。

## 何が初期に見えないか

`C_ij = integral p_r^(2i) p_perp^(2j) / E^(2(i+j)-1) dN` と書く。`rho=C00`, `pr=C10`, `pt=C01/2`。

初期 `a=b=1` では、角度部分は `mu^(2i)(1-mu^2)^j`。`2(i+j)<ell` なら

`(1/2) integral[-1,1] mu^(2i)(1-mu^2)^j P_ell(mu) dmu = 0`。

したがって粒子数、全径方向スペクトル、密度、二方向の圧力は同じであり、さらに指定した低次モーメントも同じになる。数値積分による近似的一致だけでなく、今回の有限次数の多項式積分は有理数で検算した。

## 差が入る式

前回と同じ運動論の方程式から

`dpr/dt = -(3 Ha+2 Hb)pr + Ha C20 + Hb C11`。

`ell=4` の状態対では `Delta C11=-Delta C20` なので、

`Delta(dpr/dt) = (Ha-Hb) Delta C20`、

`Delta(dpt/dt) = -(Ha-Hb) Delta C20 / 2`。

つまり**方向ごとの伸縮率の違いが、平均圧力には見えなかった方向情報を、圧力の応答の違いへ変換する**。新しい力を入れたのではない。

`R2=integral q^4/E0^3 dN0` とすると `Delta C20=16 alpha R2/315`。質量ゼロでは `R2=rho0` であり、この寄与は消えない。

## 実行結果

同じ有限固有時間 `t=.45` での `200|K_plus-K_minus|/(K_plus+K_minus)`。これは**状態対の曲率の差であり、予測誤差ではない**。各行は別の対を構成しており、情報追加による一つの予測器の精度比較ではない。

|方向の違い|最初に異なる曲率の時間微分|質量1の曲率差|質量0の曲率差|
|---|---:|---:|---:|
|P4|1階|0.741751%|2.173775%|
|P6|2階|0.142426%|0.461370%|
|P8|3階|0.042004%|0.146659%|

質量ゼロ、`rho=alpha=4/5, Ha=3/5, Hb=-1` では、最初に異なる微分の差はそれぞれ厳密な有理数で

- P4: `Delta K' = 212992/196875`
- P6: `Delta K'' = 262144/240625`
- P8: `Delta K''' = 16777216/8765625`

となった。その前の微分の差は厳密にゼロ。SymPyによる有限式の恒等式検算であり、Lean等の証明支援系による形式証明ではない。

## 数値検査と対照

主6対、追加の振幅 `.2,.5` で12対を計算した。全例を保存し、未来の差による選別はしていない。

DOP853の許容誤差を狭める検査、RK45への変更、積分点数12x32から24x64への変更を、**分布と初期幾何学を変えず**比較した。36比較で曲率の最大相対差は `3.53e-9` 以下。主6対の最大規格化重力制約残差は `4.08e-13` 以下。

以下の対照も保持した。

- 方向差ゼロでは曲率差ゼロ。
- 共通の等方スケール変化を**外から指定した運動学的対照**では、圧力とその応答の差は丸め誤差の範囲。ただしこれは連立Einstein方程式の等方的時間発展を構成したものではない。
- 以前の「質量ゼロで等方的な方向分布を固定し、径方向スペクトルだけを変える対照」も、曲率差 `2.24e-13%` 以下のまま。
- 角度を変えた積分の時間微分とモーメント方程式を複素ステップで独立に比較し、最大規格化残差 `3.81e-16` 以下。

前回の質量ゼロ対照は否定されたのではなく、**方向分布固定という条件の重要さが明確になった**。

## 限界と次の問い

この計算は、**平均密度・平均圧力では、高次の方向構造を区別できない**具体例である。一般相対論自体の破綻でも、量子的自由度の発見でもない。精密な過去履歴を含めた全観測が同じとも主張しない。

全計算は `b>=0.369` の有限区間。ブラックホール外部との接続、事象の地平面、特異点の最終状態は構成していない。一様性を仮定し、空間的なむら・衝突・二粒子相関・量子応力・回転・蒸発を含まない。質量1と0の差を同一物質の連続極限として実証したわけでもない。

次は衝突がこうした方向情報を消す時間と、幾何学がその情報を圧力へ変換する時間の競合を調べる。ただし保存則に整合した衝突モデルが必要であり、今回には未実装。
